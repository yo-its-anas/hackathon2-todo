# UI / UX / Motion Refinement Skill

## Purpose
Improve an existing application’s interface and interaction quality without altering core business logic. Focus on clarity, usability, responsiveness, and subtle motion to elevate the overall product experience.

## Instructions

1. **UI Structure & Visual Hierarchy**
   - Evaluate spacing, alignment, and layout consistency
   - Improve visual hierarchy using typography, contrast, and grouping
   - Reduce visual noise while preserving information density
   - Ensure UI scales cleanly across screen sizes

2. **UX Flow & Interaction Design**
   - Identify friction points in user flows
   - Simplify task completion paths
   - Improve affordances (buttons, inputs, states)
   - Ensure predictable navigation and feedback

3. **Motion & Micro-Interactions**
   - Add purposeful motion only where it improves clarity
   - Use transitions for state changes, loading, and feedback
   - Avoid excessive or distracting animations
   - Ensure motion respects performance and accessibility

4. **State Design**
   - Design clear loading, empty, success, and error states
   - Ensure async actions provide immediate feedback
   - Prevent UI dead-ends
   - Reflect backend state accurately in the UI

5. **Accessibility & Usability**
   - Maintain sufficient color contrast
   - Ensure keyboard navigability
   - Use semantic structure and readable text sizes
   - Avoid relying on color alone to convey meaning

6. **Consistency & Design System Alignment**
   - Reuse existing components and patterns
   - Normalize button styles, inputs, and spacing tokens
   - Align UI behavior across similar interactions
   - Avoid one-off visual exceptions unless justified

## Constraints
- Do not change backend logic or data models
- Do not introduce unnecessary libraries
- Prefer refinement over redesign
- Motion must be lightweight and optional

## Output Expectations
- Visually cleaner and more coherent UI
- Smoother and more intuitive interactions
- Subtle, intentional motion enhancements
- Improved perceived performance and polish

## Best Practices
- Clarity over creativity
- Motion should explain, not decorate
- Respect developer intent and system constraints
- Optimize for real users, not demos
- Treat UI as a system, not isolated screens
