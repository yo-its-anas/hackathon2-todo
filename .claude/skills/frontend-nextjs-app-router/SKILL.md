# Frontend Skill (Next.js App Router)

## Instructions

1. **App Router Structure**
   - Next.js 16+ App Router conventions
   - Route groups and layouts
   - Server vs Client Component boundaries
   - Loading, error, and not-found states

2. **Authentication Integration**
   - Better Auth client usage
   - Session-aware components
   - Protected routes and layouts
   - Auth state hydration and redirects

3. **Server / Client Components**
   - Server Components for data fetching
   - Client Components for interactivity
   - Minimal client-side JavaScript
   - Proper use of `use client` directive

4. **API Integration**
   - Typed fetch helpers
   - Server Actions and API calls
   - Error handling and retries
   - User-scoped requests only

5. **Responsive UI Patterns**
   - Mobile-first layouts
   - Flexible grids and stacks
   - Accessible components
   - Consistent design system usage

## Best Practices
- Default to Server Components
- Keep Client Components small and focused
- Avoid fetching data in multiple layers
- Handle auth redirects server-side
- Test layouts across breakpoints
